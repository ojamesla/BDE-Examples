# BDE Examples

Official sample projects for **Brilliant Display Editor (BDE)**.

BDE is a visual GUI development tool for ESP32 and STM32 embedded platforms.

## Download BDE

Download the latest Windows installer:

**[Download Brilliant Display Editor](https://github.com/ojamesla/BDE-Releases/releases/latest)**

## How to Download and Open

1. Download and install Brilliant Display Editor.
2. Select a demo project from the table above.
3. Click **Download raw file** on GitHub.
4. Launch BDE and select **File → Open Project**.
5. Open the downloaded `.bde` file.
6. Review the display and device configuration before exporting.

You can also download all examples using **Code → Download ZIP**.

## Version Compatibility

Some examples may require newer versions of BDE.

Projects using unsupported components or features may not work correctly in older BDE versions.

Always check the required BDE version before opening a project.

## Notes

- Demo projects are provided for learning and evaluation.
- Hardware pin assignments may differ between device models.
- Verify the device configuration before deploying to actual hardware.
